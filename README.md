# Tasks-1
make calculator in python

This Python Calculator project is a simple command-line application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division using a clean and beginner-friendly code structure. The program, contained in a single `Tasks-1.py` file, prompts the user to choose an operation and enter numbers, then processes the calculation and displays the result, handling invalid inputs and division-by-zero errors gracefully. Designed to help beginners practice Python fundamentals—such as functions, control flow, input handling, and error checking—the calculator requires only Python 3 and no external libraries, making it easy to run by executing `Tasks-1.py` in any terminal.
